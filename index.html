        Halaman 5

        Model Explanation

        Cara kerja setiap model secara ringkas, tanpa harus membaca seluruh notebook penelitian.

        SARIMAX

        Seasonal ARIMA with eXogenous regressors
        $$\phi_p(B)\,\Phi_P(B^s)\,(1-B)^d(1-B^s)^D\,y_t=\beta^\top x_t+\theta_q(B)\,\Theta_Q(B^s)\,\varepsilon_t$$

        AR(p): nilai sekarang dipengaruhi p nilai sebelumnya. I(d): differencing d kali agar deret stasioner. MA(q): dipengaruhi q galat (shock) sebelumnya. Notasi \(B\) adalah operator backshift: \(B y_t = y_{t-1}\).

        \((P,D,Q)_s\) adalah versi musiman dengan periode \(s\) (di sini \(s=24\) jam). Variabel eksogen \(x_t\) (Fourier mingguan, libur, sekolah, dan cuaca untuk model beban) masuk sebagai regresi; galatnya dimodelkan SARIMA.

        Parameter diestimasi dengan maximum likelihood (filter Kalman). Ramalan 24 jam dihasilkan rekursif: ramalan jam ke-h memakai ramalan jam-jam sebelumnya.
        Kelebihan
        • Interpretable
        • Parsimoni
        • Interval teoretis
        Keterbatasan
        • Hubungan linear
        • Berat untuk data per jam panjang
        • Galat menumpuk di horizon jauh

        XGBoost

        eXtreme Gradient Boosting · decision tree ensemble
        $$\hat y^{(m)}=\hat y^{(m-1)}+\eta\,f_m(x),\qquad f_m=\arg\min_f\sum_i \ell\big(y_i,\hat y_i^{(m-1)}+f(x_i)\big)+\Omega(f)$$
        • Residual learning: setiap pohon baru belajar memperbaiki galat (gradien) gabungan pohon sebelumnya.
        • Lag features: nilai deret pada jam-jam sebelumnya (mis. 1, 2, 3, 24, 168 jam).
        • Rolling statistics: rata-rata/simpangan pada jendela bergerak (dipilih dengan validasi).
        • Feature importance: kontribusi tiap fitur (gain / SHAP), lihat Halaman 4-D.
        • Direct multi-step: 24 model terpisah, satu per horizon, sehingga galat tidak menumpuk.

        SARIMAX untuk beban

        • Historis beban dengan differencing \((1-B)(1-B^{24})\).
        • Orde terpilih: –.
        • Pola mingguan via Fourier \(K=4\) + libur + sekolah.
        • Skenario B/C: menambah regresor cuaca pada \(x_t\).

        XGBoost untuk beban

        $$\hat y_{t+h}=f_h\big(y_t..y_{t-167},\,y_{t+h-24},\,y_{t+h-168},\,\text{kalender}_{t+h},\,\text{cuaca}_{t+h}\big)$$
        • 24 model direct (h = 1..24).
        • Lag beban terakhir + lag “jam yang sama” kemarin & minggu lalu.
        • Kalender pada waktu target (jam, hari, musim, libur, sekolah).
        • Cuaca pada waktu target: aktual saat training, ramalan BAB I saat operasional.

        TimesFM 3.0

        • Time Series Foundation Model dari Google (decoder-only transformer).
        • Pretraining pada korpus deret waktu publik berukuran sangat besar.
        • Zero-shot: tidak dilatih ulang pada data Panama.
        • Context window: – jam terakhir sebagai input.
        • Horizon: 24 jam, keluaran median + kuantil 0,1–0,9.

        Context window vs horizon

        Geser untuk melihat berapa banyak riwayat yang “dibaca” TimesFM sebelum meramal 24 jam.
